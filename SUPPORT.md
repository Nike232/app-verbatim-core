# Support

App Verbatim Core is community-maintained software. The latest GitHub release is the only supported version; the moving `v0` Action tag follows that release.

## Where to ask

- Use [GitHub Discussions](https://github.com/Nike232/app-verbatim-core/discussions) for setup help, usage questions, and workflow advice.
- Use the issue templates for reproducible bugs, focused feature proposals, and connector breakage.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Never include an exploit, credential, cookie, private dataset, or personal data in a public issue or discussion.

Maintainers provide best-effort community support without a response-time SLA. Hosted operations, private data sources, team administration, and commercial support are outside this repository's scope.
