# Code of Conduct

We want participation in App Verbatim Core to be respectful, technically honest, and safe.

Be considerate, critique ideas rather than people, disclose conflicts of interest, and avoid harassment, threats, discrimination, doxxing, or publication of private data. Maintainers may edit or remove abusive content and restrict participation when necessary.

Report conduct concerns privately through the repository maintainer's GitHub profile or repository private-reporting channel. Good-faith technical disagreement is welcome; personal attacks are not.
